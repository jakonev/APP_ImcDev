# Flutter
![Alt text](https://res.cloudinary.com/dsiexpoig/image/upload/v1790080108/flutter_iobo4o.jpg)
🎓 é a tecnologia/ferramenta de criação (um framework ou SDK). Ele fornece os blocos de construção (widgets), botões e lógicas para o aplicativo funcionar tanto no Android quanto no iOS com o mesmo código.
